# Rule-Based Expert System (Python)

This project demonstrates a simple **Rule-Based Expert System** using
**forward chaining** to make decisions based on predefined rules.

## Features
- IF–THEN rule evaluation
- Forward chaining inference engine
- Easy-to-extend rule base
- Beginner and interview friendly

## Example Use Case
Medical diagnosis based on symptoms.

```bash
git clone https://github.com/Yesureddy91/rule-based-expert-system.git
cd rule-based-expert-system
